# Аналитика розничных продаж (портфельный проект)

Комплексный проект в стиле **аналитика данных**: синтетические B2C заказы, **SQL аналитика** (DuckDB), **Python** конвейер, диаграммы **matplotlib**, опциональный UI **Streamlit**. Подходит для размещения в CV или профиле GitHub.

## Бизнес-вопрос

Как развиваются **GMV**, **категорийный микс**, **средняя стоимость заказа по странам** и **удержание когорт по регистрации** для многостранного интернет-магазина?

## Что внутри

| Путь | Описание |
|------|----------|
| `data/*.csv` | Небольшой **демо** датасет (работает сразу из коробки). Замените, запустив `scripts/generate_data.py` для ~1.2k клиентов / ~6 месяцев. |
| `sql/*.sql` | Аналитические запросы (месячный GMV, категории, AOV по странам, топ продукты, удержание когорт). |
| `src/run_pipeline.py` | Загружает CSV в DuckDB, выполняет все `.sql`, записывает `outputs/*.csv` и `reports/*.png`. |
| `streamlit_app.py` | Легкий просмотрщик таблиц и диаграмм. |

## Быстрый старт

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux
pip install -r requirements.txt
python src/run_pipeline.py      # использует CSV из папки data/
streamlit run streamlit_app.py
```

Перегенерировать больший синтетический датасет (детерминированный `seed=42`):

```bash
python scripts/generate_data.py
python src/run_pipeline.py
```

## Метрики (определения)

- **GMV** — сумма `(quantity - quantity_returned) * unit_price_paid` для строк, связанных с заказами со статусом `completed` или `returned` (поддерживаются частичные возвраты). Заказы со статусом `cancelled` исключаются.
- **AOV** — GMV разделённый на количество уникальных заказов в срезе.
- **Месяц когорты** — календарный месяц `signup_date`; **удержание** — доля клиентов когорты с хотя бы одним квалифицирующим заказом в месяц `регистрация + смещение` (смещения 0–3).

## Пункты для резюме

- Построил комплексный **портфель аналитики розничной торговли**: **SQL** метрики по заказам, возвратам и **когортам** по регистрации клиентов, выполненные с помощью **DuckDB**, экспортированные артефакты для отчётности.
- Доставил анализы **GMV / AOV / категорийного микса** и диаграммы **matplotlib**, а также **Streamlit** обозреватель для заинтересованных сторон.
- Добавил **воспроизводимую генерацию синтетических данных** (с заданным seed) и **GitHub Actions** рабочий процесс, который регенерирует данные и запускает полный конвейер при каждом push.
